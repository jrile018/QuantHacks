## Top three

1. **Greenhouse hiring:** The public can view each job at posting, but is unlikely to monitor and classify daily roles across many small biotech boards. This is a prospective signal only until a real snapshot history accumulates.
2. **EMA agenda stages:** The public can read the PDF at release, but mapping medicine names and review stages to a US microcap quickly requires specialist work. Check for a same-day company release before trading.
3. **FDA recall reports:** The public can search each report at release, but mapping a product or contract manufacturer to a small sponsor is tedious. Use `report_date` or first observed time, never `recall_initiation_date`, for availability.

## Ready-to-run first pull

Run `python biological_products/scripts/30_pull_greenhouse_jobs.py`. It snapshots three verified boards: BEAM, MAZE, and PRME. The API returned 41, 16, and 7 open jobs respectively on 2026-10-04. Raw JSON is cached under `data/raw/greenhouse_jobs/YYYYMMDD/`, and a second run on the same date reads the cache. Extend with `--board TICKER=board_token` after verifying a company-owned board URL and the ticker to CIK mapping. Run once daily after the close. The source is free and requires no account or key. The checked fields are `id`, `title`, `first_published`, `updated_at`, `location`, `departments`, `offices`, and `content`.

### Feature builder plan

Join ticker to CIK through `fds_lookup_cik_ticker.csv`. Make `(board, id)` the job key. Store the first snapshot date when each job was actually seen and do not backfill older snapshots from `first_published`. Use the later of `first_published` and first seen, plus one calendar day, as usable time. Numeric company-day features could include new commercial roles in 30 and 90 days, manufacturing roles in 90 days, total open jobs, and role counts divided by recent total open jobs. Mark periods before monitoring began as missing, not zero. A later API edit must not alter earlier feature rows.

### Test plan

First, track job openings and closings prospectively and audit 100 random company-days against saved snapshots. Then run an event study for the first commercial hiring burst with entry at the next market open and exits after 5 and 20 market days, minus XBI over each same window. Use only stocks with $1 million ADV and $1 raw close, cluster by company-month, exclude events around 8-Ks and company news, and compare with matched company random days. Model spread and slippage; prefer a long-only or avoid signal because microcap shorts can be costly. There is no valid 2024-2026 backtest from today's open-job feed alone.

## Other source checks and timing cautions

- FDA inspections have a long classification lag, and the checked [dashboard](https://datadashboard.fda.gov/oii/cd/inspections.htm) bulk workbook link returned 404. Its API needs an authorization key. It is not a quick historical signal tonight.
- [FDA advisory briefing documents](https://www.fda.gov/advisory-committees/about-advisory-committees/common-questions-and-answers-about-fda-advisory-committee-meetings) are free and normally posted before a meeting, but biotech traders watch them closely, so the attention wedge is weak.
- SEC [comment letters](https://www.sec.gov/about/divisions-offices/division-corporation-finance/filing-review-process-corp-fin) can be made public weeks after the letter's own date. An EDGAR filing date alone is unsafe as the first-public date.
- XBI uses [modified equal weights and liquidity caps](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-select-industry-indices.pdf), and its rebalance is widely watched. Current holdings cannot reconstruct historical weights.
