# Architecture change-impact index

Read the [entry](../CONTEXT.md), then the affected card. Graph edges are navigation evidence; verify the owning source before changing code.

| Change | Direct owner/consumer | Transitive impact | Acceptance to repeat |
|---|---|---|---|
| Raw source version or adjudication | Evidence/industry → source adapters | Facts, relationships, features, labels, event opportunities | Hashes + retained versions + quarantine exclusion |
| Public/receipt/replay clock | Evidence/Benchmark/Post → materializer | Eligible rows, surprise definitions, forecast sample | Availability counterexample and cutoff basis |
| Security/contract/calendar | Universe/market → decisions/market importer | Targets, roll/actions, trade capacity and portfolio exposures | Dated identity and class/session fixture |
| Feature definition/amount/role/unit | Producer → registry/materializer | Ablations, interpretation and fitted model | Exact version/unit/scope/period and role review |
| Target units/horizon/sample | Market/Lattice → evaluator | Loss metrics, economic mapping and promotion | Expected-unit and matched-opportunity checks |
| Regime/risk policy | Policy owner → frozen orders/portfolio | Exposure, drawdown/liquidity/cash and comparators | Separate trial + exposure/cost/lifecycle rules |
| Spending writer/store | Every buyer → shared guard | Outstanding reserves and duplicate submission risk | Same absolute DB + atomic/idempotent reservation |
| Source/config/code edit | Owning lane → accepted manifest | Every declared downstream card/run | Fingerprint refresh and affected gate rerun |

Unresolved/conditional edges: industry quarantine lineage into all canonical records; receipt verification and canonical qualification of the evaluator unit guard; forecast-to-order policy; options/futures economic lifecycle; adoption by all paid buyers.

If a source hash changes, mark affected cards stale. A directory addition can change a bounded absence claim. Preserve old accepted snapshots; a new map does not rewrite run history.
